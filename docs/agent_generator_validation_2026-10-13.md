## 实际长度与预算

以下以应用等权、pattern按发生概率统计；token按实际逐次请求计数。另有基准到达率加权统计存入manifest，不能与该口径混用。

| 量 | 目标P50 / P90 | 实际P50 / P90 | 实际范围 | 偏度 |
|---|---|---|---|---|
| 完整输入，含历史 | 2048 / 8192 | 2105 / 8075 | 256–16384 | 1.691 |
| 输出 | 200 / 1200 | 200 / 1177 | 16–2032 | 1.643 |
| 工具可见文本 | 256 / 1500 | 256 / 1493 | 49–4963 | 2.517 |
| 执行LLM数 | 2 / 未冻结 | 2 / 4 | 1–15 | 3.726 |

所有正概率pattern逐个通过单次输入+输出≤32768和执行累计≤128000检查，累计包含历史被重复prefill的工作量。并行汇聚按消息标识去重，新增输入在抽样前预留其进入后续LLM的费用。最终接受的长度记录合计经历20次失败候选重抽；图结构、概率和pattern集合不因这些重抽而改变。实际分位数接近但不伪装成恰好等于目标。

## 自动测试与接口核验

242个测试通过，其中新增生成器测试34个。执行集合为Git跟踪的测试文件加`tests/test_agent_generator.py`，没有运行或修改既有未跟踪的历史路由探针。

```powershell
$taskTests = @(git ls-files -- 'tests/test_*.py') + @('tests/test_agent_generator.py')
python -B -m pytest @taskTests -q -p no:cacheprovider
```

覆盖项目包括：20组固定种子结构/预算检查、无环与正概率节点覆盖、控制树独立重放、串并行与互斥概率语义、单LLM例外、局部并行与全图层宽区别、消息去重、两级预算、条件代表均值、应用去编号身份、私有工具归属、无闲置工具、嵌套子集、读取保存池而不重新抽样、工具重绑定不变性及损坏数据拒绝。

所有生成YAML已通过生产`ScenarioLoader`往返核验；生成场景可进入既有模型选择环境和固定时隙轨迹。紧凑DAG的拓扑关键路径与旧链列表在等价输入下结果一致，保留“先取具体执行映射最大值，再求概率平均”的定义。每个pattern的最终输出量用于相应回传负载，而不是取另一条分支的输出量。

测试中的NetworkX有向图哈希版本提示不影响同构判定：哈希仅筛选比较候选，最终身份仍由图同构核验；库版本已记录，跨版本复现时需使用相同软件版本。
