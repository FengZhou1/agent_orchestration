## 1. 第四章实际做了什么（必须先说清，因为它和"学路由"不是一回事）

| 项 | 第四章的做法 |
|---|---|
| 决策变量 | **部署**：把"当前排队的那个微服务"的一个实例放到哪台服务器（\|N\| 个离散选择） |
| 路由概率 | **不是学的**。由 CPR 算法解析给出：`p ∝ 目的节点上的实例数 / Σ 实例数`（算法 4.2 第 6–12 行），即"按实例数公平分摊" |
| 一步一个动作 | 是。原文 p.115："最小编排单元为单个微服务实例，在每个决策时间步 τ 只能离散地部署一个实例"；"哪个微服务"由 DAFG 拓扑决定的待部署队列给出 |
| 多时间尺度 | 不是双 actor，而是**四类事件触发**（实例级／微服务级／DAFG 级／离散时隙级）决定何时计算外部奖励、何时调用 CPR |
| 状态 | 五项：节点与链路资源、部署状态、当前待编排微服务的属性、**上一时间步已部署实例的配置**、DFP 时变信息（含平均到达率）；**路由概率不在状态里**，到达率只以聚合值出现 |
| 奖励 | 三项**差值**：成本、全局平均利用率、累积期望响应时延；基准是**上一轮训练中同一时隙**的值（`C^last(τ)`、`U^last(τ)`、`E_last(τ)`），不是上一时隙 |
| 计分与探索 | 中间步只给 ICM 内在奖励（"环境未返回外部奖励时…由内在好奇心机制提供内在奖励"）；非法动作靠动作掩码（对数概率置 −1e9）规避，不用负奖励 |

**该章没有模型维度**（纯微服务 + GI/M/C 排队），所以"各模型的路由"在那一章没有对应物，属于类比改写。

**其奖励数值无法直接复用**：K₁…K₄ 与 δ_c/δ_u/δ_resp 全章未给；且成本与时延两项的差值方向与它自己的最小化目标相反（疑似漏负号）。

## 2. 本次采用的四个口径（来自你的回答）

1. **学路由**（不是学部署）：一步决定一个 (应用, 入口) 组的模型份额。
2. **索引维度 = (应用, 入口) 组**：与现有组成变量 `x_{a,g,m}` 一致（20 组 × 4 模型 = 80 维）。
3. **取值可以连续**：每步输出该组的份额向量（主设置）；硬选一个模型作为消融。
4. **差值两种都算，训练用一个**：`delta_step`（本时隙 − 上一时隙）与 `delta_round`（本时隙 − 上一轮同一时隙）。

## 3. 复用映射与两处必须偏离的地方

**复用**（`src/agent_orch/envs/composition_sequential_env.py`）：

- **一步一个决策单元** → 一个时隙内按固定顺序走 `n_groups` 个子步，子步 `g` 只决定组 `g` 的份额行；
  其余组沿用当前工作组成（= 上一时隙的决策结果）。
- **外部奖励只在单元完成时到达** → 中间子步返回 0 外部奖励（rollout 照旧叠加 RND 内在奖励），
  最后一个子步才跑一次仿真。**因此一个时隙仍只花一次仿真**，不是 `n_groups` 次。
- **上一步的配置进状态** → 工作组成（20×4）作为特征附加进观测，对应第四章状态第 (4) 项。
- **动作掩码** → 沿用；非激活模型的份额恒为 0。

**偏离（因为第四章没有对应物，写明而不是自己编）**：

- **差值对象**用我们自己的四项效用 `U(t)`（权重取自场景配置），并且定义成"提升为正"。
  第四章的三项差值与它自己的最小化目标符号不一致，且权重／阈值缺失，照抄会引入错误符号。
- **不做小变化门控**（δ）。第四章的 δ 是把"变化太小"的情形交给内在奖励；我们的中间子步已经
  只给内在奖励，门控没有额外作用。

**一处必须做的策略侧改动**：策略的 log-prob 与熵**只对被动作的那一组**计算
（`_sample_grouped_dirichlet` / `_evaluate_grouped_dirichlet` 新增 `only_group`，组索引随观测走）。
否则 PPO 的比值会包含环境丢弃的另外 19 行，把梯度按分解本要消除的比例稀释。
该改动对整向量环境是惰性的（键不存在即为原行为）。
