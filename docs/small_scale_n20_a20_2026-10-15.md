## 3. 只训练模型选择的命令

先用100轮观察小规模训练趋势。这是显式诊断预算，不是正式收敛预算。若启动前希望使用其他轮数，同时调整`--updates`和`--route-updates`；不能仅修改其中一个，否则可能进入其他阶段。

```powershell
cd C:\Users\01\Desktop\agent\experiments\agent_orchestration
conda activate agent-orch
$env:PYTHONPATH='src'
$env:PYTHONIOENCODING='utf-8'

python -u scripts/run_slot_joint.py `
  --scenario results/slo_calibrated_main_20261014/servers_20_applications_20.yaml `
  --warmup-bundle results/warmup_n20_a20_32slots_20261015 `
  --output results/composition_n20_a20_32slots_s0 `
  --slots 32 `
  --updates 100 --route-updates 100 --deploy-updates 0 `
  --mapping-samples 128 `
  --seed 0 --trajectory-seed 101 --warmup-seed 20261014 `
  --device cpu
```

随机初始化，仅训练模型选择actor及其critic；部署分支冻结。共享条件化模型选择头、4层×256、学习率1e-4、小批量32、PPO epoch3等沿用当前登记配置，不引入教师或蒸馏。没有复用50应用的权重、奖励历史或轨迹。

本轮没有修改造成此前学习退化的观测编码、首轮参照或信用分配机制。因此这是缩小规模后的定位对照，不声称已经修复不收敛。

2026-10-15：原运行检查点已保存100次PPO更新。用户要求继续观察收敛；以下将总预算延长至1000轮，新增900轮，始终处于模型选择阶段，不进入部署或联合训练。
